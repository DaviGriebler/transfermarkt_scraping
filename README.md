# Transfermarkt Scraping & Power BI Analysis

A data scraping and visualization project that collects football data from **Transfermarkt** using Python and transforms the extracted information into interactive **Power BI dashboards**.

The project was developed to create a structured dataset from publicly available Transfermarkt pages and use it to analyze historical football performance, with a particular focus on the **Premier League**.

## Project Overview

The project is divided into two main stages:

1. **Web Scraping** — Python scripts collect and process football data from Transfermarkt.
2. **Data Visualization** — The generated CSV files are used as data sources for Power BI dashboards and analytical reports.

The scraping process was designed to collect data across multiple seasons and organize it into datasets that can be related through identifiers such as seasons, rounds, matches, teams, and players.

## Data Collected

The scraping scripts retrieve different types of information from Transfermarkt, including:

* country-flags.csv
* premier-events.csv
* premier-logos.csv
* premier-matches.csv
* premier-placements.csv
* premier-squad.csv
* premier-titles.csv
* premier-top-scorers.csv

The generated datasets are stored as CSV files and later imported into Power BI. Extracted information is cleaned and standardized using Python and Pandas.

This stage includes tasks such as:

* Creating unique keys for seasons, rounds, and matches
* Converting market values into numeric formats
* Handling missing values
* Standardizing country names
* Structuring match and event information
* Preparing relationships between datasets

## Power BI Dashboard

The Power BI section of the project transforms the scraped data into an analytical model and interactive dashboards.

The reports explore topics such as:

* Goals and scoring trends
* Home vs. away performance
* Points accumulated by clubs
* Club performance across Premier League seasons
* Penalties scored and missed
* Own goals
* Final league positions
* Seasons played
* Player and team statistics
* Historical Premier League trends

The Power BI model connects the different datasets created by the scraping process, allowing the dashboards to analyze information across seasons, teams, matches, players, and events.

Additional calculations and analytical metrics are created using **DAX**, enabling comparisons across clubs, seasons, matches, players, and events.

## Updating the Data

Because the scraper is based on season parameters, the datasets can be updated by running the scraping scripts for additional or ongoing seasons.

After generating updated CSV files, the Power BI report can be refreshed to incorporate the new data.

## Important Notes

This project is intended for **educational, analytical, and portfolio purposes**.

Transfermarkt is a third-party website and its HTML structure may change over time. Changes to page layouts, CSS classes, URLs, or anti-scraping mechanisms may require modifications to the scraping scripts.

When running the scraper, requests should be made responsibly and with appropriate intervals between requests.
